Level indicator 量表

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 顯示一個量落在範圍哪裡，例如硬碟用了多少

也叫：gaugelevel indicator儀表

AI prompt

Build a macOS Level indicator (NSLevelIndicator). Also known as: HTML meter element, gauge. It should have: value within a known range; color changes past thresholds. Do not build a Progress bar.
