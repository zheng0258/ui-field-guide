  • 小小的圓角標籤，標示狀態或分類

也叫：chiptagpilllabel標籤

範例

HTML 原始碼

  >收件人：
  <span class="tokens">

    <span class="token">Amy Chen</span>
    <input aria-label="新增收件人" />
  </span>
</label>

AI prompt

Build a macOS Token (NSTokenField). Also known as: tag chip, status pill. It should have: small rounded label; short text or count.
