範例

匯出為 PDF

HTML 原始碼
<button type="button" class="btn" data-open="mac-sheet">匯出…</button>
<dialog id="mac-sheet" class="sheet" aria-labelledby="mac-sheet-title">
  <h3 id="mac-sheet-title">匯出為 PDF</h3>
  <div class="form">
    <label class="label" for="mac-sheet-name">名稱：</label>
    <input id="mac-sheet-name" class="field" value="報告.pdf" />
  </div>
  <div class="row">
    <button type="button" class="btn" data-close>取消</button>
    <button type="button" class="btn btn-default" data-close>儲存</button>
  </div>
</dialog>

AI prompt

Build a macOS Sheet (NSWindow.beginSheet or .sheet). Also known as: HTML dialog element, showModal, APG dialog pattern. It should have: focus trapped inside; Escape closes; backdrop dims page. Do not build a Popover.
