Segmented control 分段控制

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 幾顆並排黏在一起的按鈕，一次選一個
  • 一條橫向膠囊切成好幾格，選中的那格會反白

也叫：segmented buttonbutton grouptoggle group分段按鈕

AI prompt

Build a macOS Segmented control (NSSegmentedControl or Picker(.segmented)). Also known as: NSSegmentedControl, SwiftUI Picker segmented style. It should have: joined segments; one selected segment highlighted. Do not build a Switch.
