Window 視窗

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 一個 App 的框框，最上面有紅黃綠三顆圓點和標題
  • 點到別的視窗時，紅黃綠會變灰

也叫：app windowtitle bartraffic lights視窗標題列紅黃綠按鈕

範例

下載項目
非作用中視窗
文件
作用中視窗。點後面的視窗試試看。
HTML 原始碼
<div class="window-stack" data-window-stack>
  <div class="window" data-active="false">
    <div class="titlebar">
      <div class="lights lights-buttons">
        <button type="button" aria-label="關閉"></button>
        <button type="button" aria-label="縮到最小"></button>
        <button type="button" aria-label="放到最大"></button>
      </div>
      <span class="window-title">下載項目</span>
    </div>
    <div class="window-body muted">非作用中視窗</div>
  </div>
  <div class="window" data-active="true">
    <div class="titlebar">
      <div class="lights lights-buttons">
        <button type="button" aria-label="關閉"></button>
        <button type="button" aria-label="縮到最小"></button>
        <button type="button" aria-label="放到最大"></button>
      </div>
      <span class="window-title">文件</span>
    </div>
    <div class="window-body muted">作用中視窗。點後面的視窗試試看。</div>
  </div>
</div>

AI prompt

Build a macOS Window (NSWindow + standardWindowButton or WindowGroup / Window). Also known as: NSWindow, traffic light window controls. It should have: title bar with red, yellow and green buttons; controls turn gray when the window is inactive; rounded corners and soft shadow. Do not build a Modal dialog.
