Context menu 情境選單

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 按右鍵或長按才會跳出來的選單
  • 針對你點的那個東西列出能做的事

也叫：right-click menushortcut menulong-press menu右鍵選單長按選單

範例

報告.pdf 按右鍵或 Shift+F10
HTML 原始碼
<div class="window" style="width: 300px">
  <div class="window-body">
    <div
      tabindex="0"
      data-contextmenu="mac-context"
      class="stack"
      style="place-items: center; padding: 18px; border-radius: 8px; border: 1px dashed var(--m-separator)"
    >
      報告.pdf
      <small class="muted">按右鍵或 Shift+F10</small>
    </div>
  </div>
</div>
<div id="mac-context" popover role="menu" class="menu menu-floating">
  <button type="button" role="menuitem">打開</button>
  <button type="button" role="menuitem">取得資訊 <kbd>⌘I</kbd></button>
  <hr />
  <button type="button" role="menuitem">拷貝「報告.pdf」</button>
  <button type="button" role="menuitem">移到垃圾桶</button>
</div>

AI prompt

Build a macOS Context menu (NSMenu (NSView.menu) or .contextMenu). Also known as: right-click menu, SwiftUI contextMenu. It should have: appears at pointer; actions for the clicked item. Do not build a Pull-down menu.
