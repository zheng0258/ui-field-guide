Listbox 清單選擇

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 直接攤開在畫面上的選項清單，可以選一個或多個

也叫：multi-selectlist box多選清單

範例

HTML 原始碼
<label class="field"
  >技能（可多選）
  <select multiple size="4">
    <option selected>Vue</option>
    <option>React</option>
    <option selected>TypeScript</option>
    <option>Swift</option>
  </select>
</label>

容易搞混

  • Combo box（組合框）
  • Pop-up select（彈出式選擇）

AI prompt

Build a Web Listbox (<select multiple> or listbox + option). Also known as: APG listbox pattern, select multiple. It should have: always-visible list of options; selected options highlighted. Do not build a Pop-up select.
