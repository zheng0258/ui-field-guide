Modal dialog 對話框

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 蓋在整個畫面上、要處理完才能回去的視窗

也叫：modallightboxdialog彈窗跳窗

範例

編輯個人資料

HTML 原始碼
<button type="button" class="btn btn-primary" data-open="modal-dialog-box">編輯個人資料</button>
<dialog id="modal-dialog-box" aria-labelledby="modal-dialog-title" class="dialog">
  <form method="dialog">
    <h3 id="modal-dialog-title">編輯個人資料</h3>
    <label class="field">顯示名稱 <input type="text" value="Yobbo" /></label>
    <div class="row end">
      <button type="button" class="btn" data-close>取消</button>
      <button type="submit" class="btn btn-primary">儲存</button>
    </div>
  </form>
</dialog>

AI prompt

Build a Web Modal dialog (<dialog> + showModal() or dialog + aria-modal). Also known as: HTML dialog element, showModal, APG dialog pattern. It should have: focus trapped inside; Escape closes; backdrop dims page. Do not build a Popover.
