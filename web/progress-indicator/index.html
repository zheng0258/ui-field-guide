Progress bar 進度條

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 一條慢慢填滿的橫條，表示完成多少

也叫：progressloading bar進度

範例

HTML 原始碼
<label class="field"
  >上傳中（64%）
  <progress max="100" value="64">64%</progress>
</label>

AI prompt

Build a Web Progress bar (<progress> or progressbar). Also known as: HTML progress element. It should have: horizontal bar filling left to right; percentage label. Do not build a Meter.
