Data grid 資料格

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 像試算表一樣，可以用方向鍵一格一格移動、排序

也叫：gridspreadsheet資料表格

範例

鍵盤32400
滑鼠12890
螢幕57600
HTML 原始碼
<table role="grid" aria-label="庫存" class="table grid">
  <thead>
    <tr>
      <th scope="col"><button type="button" data-sort>品名</button></th>
      <th scope="col" aria-sort="ascending"><button type="button" data-sort>數量</button></th>
      <th scope="col"><button type="button" data-sort>價格</button></th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td tabindex="0">鍵盤</td>
      <td>3</td>
      <td>2400</td>
    </tr>
    <tr>
      <td tabindex="-1">滑鼠</td>
      <td>12</td>
      <td>890</td>
    </tr>
    <tr>
      <td tabindex="-1">螢幕</td>
      <td>5</td>
      <td>7600</td>
    </tr>
  </tbody>
</table>

AI prompt

Build a Web Data grid (<table> + JavaScript or grid). Also known as: APG grid pattern, role grid. It should have: arrow key cell navigation; sortable headers. Do not build a Table.
