Scroll container 捲動視圖

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 內容比框框大時可以上下捲動的區域
  • 捲軸平常隱藏，捲動時才出現

也叫：scroll areascrollerscrollbar捲軸捲動區

範例

  • 報告
  • 預算
  • 照片
  • 筆記
  • 簡報

AI prompt

Build a Web Scroll container (overflow: auto + tabindex="0" or region with aria-label). Also known as: NSScrollView, overlay scrollbar. It should have: content clipped to a frame; thin overlay scroller that fades out; keyboard scrollable when focused.
