Treegrid 樹狀表格

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 有很多欄位、每一列又能展開子列的表格

也叫：tree table可展開表格

範例

主旨寄件者日期
下週會議Amy10/27
Re: 下週會議Ben10/27
Re: 下週會議Amy10/28
發票寄送會計部10/26

      <th scope="col">日期</th>

      <td>Amy</td>
      <td>10/27</td>

    <tr role="row" aria-level="2" data-parent="treegrid-r1">

AI prompt

Build a Web Treegrid (treegrid). Also known as: APG treegrid pattern, expandable table rows. It should have: rows expand to show child rows; multiple columns. Do not build a Tree view.
