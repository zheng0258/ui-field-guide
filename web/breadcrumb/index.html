Breadcrumb 麵包屑

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 顯示「首頁 > 分類 > 目前頁面」的路徑

也叫：path路徑導覽

範例

  1. 首頁
  2. 文件
  3. 安裝指南
HTML 原始碼
<nav aria-label="麵包屑" class="breadcrumb">
  <ol>
    <li><a href="#breadcrumb-demo">首頁</a></li>
    <li><a href="#breadcrumb-demo">文件</a></li>
    <li><a href="#breadcrumb-demo" aria-current="page">安裝指南</a></li>
  </ol>
</nav>

AI prompt

Build a Web Breadcrumb (<nav> + <ol> or navigation + aria-current="page"). Also known as: nav aria-label breadcrumb, ordered list. It should have: separators between links; current page with aria-current.
