Accordion 手風琴

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 好幾段標題，一次只展開其中一段

也叫：collapseexpander摺疊面板

範例

可以退款嗎？

購買後 14 天內可全額退款。

支援哪些付款方式？

信用卡與銀行轉帳。

如何取消訂閱？

在帳號設定的「訂閱」頁面取消。

HTML 原始碼
<div class="accordion">
  <details name="accordion-faq" open>
    <summary>可以退款嗎？</summary>
    <p>購買後 14 天內可全額退款。</p>
  </details>
  <details name="accordion-faq">
    <summary>支援哪些付款方式？</summary>
    <p>信用卡與銀行轉帳。</p>
  </details>
  <details name="accordion-faq">
    <summary>如何取消訂閱？</summary>
    <p>在帳號設定的「訂閱」頁面取消。</p>
  </details>
</div>

AI prompt

Build a Web Accordion (<details name> group or button[aria-expanded] + region). Also known as: details summary with name attribute. It should have: one section open at a time; chevron rotates. Do not build a Disclosure.
