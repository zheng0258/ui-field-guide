Select 彈出式選擇

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 點開後選一個值，按鈕上會顯示目前選的那個
  • 一顆按鈕，右邊有上下箭頭，點開是選項清單

也叫：dropdownselectpicker下拉選單下拉

範例

HTML 原始碼
<label class="field"
  >排序方式
  <select>
    <option>最新</option>
    <option selected>最熱門</option>
    <option>價格由低到高</option>
  </select>
</label>

AI prompt

Build a Web Select (<select> or combobox (Select-Only)). Also known as: NSPopUpButton, SwiftUI Picker menu style. It should have: shows current selection; up-down chevron on right. Do not build a Pull-down menu.
