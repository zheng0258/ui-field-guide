Pagination 分頁器

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 一排頁碼，加上上一頁、下一頁

也叫：pager頁碼

範例

‹ 1 2 3 … 12 ›
HTML 原始碼
<nav aria-label="分頁" class="pagination">
  <a href="#pagination-demo" aria-label="上一頁">‹</a>
  <a href="#pagination-demo">1</a>
  <a href="#pagination-demo" aria-current="page">2</a>
  <a href="#pagination-demo">3</a>
  <span aria-hidden="true">…</span>
  <a href="#pagination-demo">12</a>
  <a href="#pagination-demo" aria-label="下一頁">›</a>
</nav>

AI prompt

Build a Web Pagination (<nav> + <a> or navigation + aria-current="page"). Also known as: pager navigation. It should have: previous and next links; numbered page links, current page highlighted.
