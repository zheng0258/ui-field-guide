Navigation 導覽列

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

範例

Acme
  • 首頁
  • 產品
  • 價格
  • 聯絡
HTML 原始碼
<nav aria-label="主要導覽" class="navbar">
  <a href="#navigation-demo" class="navbar-brand">Acme</a>
  <ul>
    <li><a href="#navigation-demo" aria-current="page">首頁</a></li>
    <li><a href="#navigation-demo">產品</a></li>
    <li><a href="#navigation-demo">價格</a></li>
    <li><a href="#navigation-demo">聯絡</a></li>
  </ul>
</nav>

容易搞混

  • Pull-down menu（下拉式動作選單）
  • Tabs（分頁標籤）

AI prompt

Build a Web Navigation (<nav> or navigation landmark). Also known as: nav landmark. It should have: horizontal list of page links; current page highlighted with aria-current. Do not build a Pull-down menu.
