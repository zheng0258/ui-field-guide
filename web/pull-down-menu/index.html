Menu button 下拉式動作選單

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 按鈕點開是一串動作，按鈕上的字不會變
  • 「更多」按鈕點開的指令清單

也叫：menu buttondropdown menuactions menu更多選單動作選單

範例

HTML 原始碼
<button type="button" class="btn" popovertarget="pull-down-menu-list" aria-haspopup="menu">
  動作 <span aria-hidden="true">▾</span>
</button>
<div id="pull-down-menu-list" popover role="menu" class="menu">
  <button type="button" role="menuitem">重新命名</button>
  <button type="button" role="menuitem">複製</button>
  <hr />
  <button type="button" role="menuitem" class="danger">刪除</button>
</div>

容易搞混

  • Pop-up select（彈出式選擇）
  • Context menu（情境選單）

AI prompt

Build a Web Menu button (<button> + popover or button[aria-haspopup=menu] + menu). Also known as: menu button, SwiftUI Menu. It should have: button label stays fixed; opens a list of commands; chevron down. Do not build a Pop-up select.
