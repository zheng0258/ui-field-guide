  • 從下方跳出的一串選項，最下面通常是「取消」

範例

這會清除所有瀏覽記錄。

HTML 原始碼
<button type="button" class="btn" data-open="ios-actionsheet">清除歷史記錄…</button>
<dialog id="ios-actionsheet" class="actionsheet" aria-label="清除歷史記錄">
  <div class="actionsheet-group">
    <p>這會清除所有瀏覽記錄。</p>
    <button type="button" data-close>清除最近一小時</button>
    <button type="button" class="danger" data-close>清除全部</button>
  </div>
  <div class="actionsheet-group actionsheet-cancel">
    <button type="button" data-close autofocus>取消</button>
  </div>
</dialog>

AI prompt

Build a iOS Action sheet (UIAlertController (.actionSheet) or .confirmationDialog). Also known as: SwiftUI confirmationDialog, UIAlertController actionSheet. It should have: list of choices slides up from bottom; destructive option in red; separate Cancel button. Do not build a Alert dialog.
