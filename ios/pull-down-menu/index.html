Pull-down button 下拉式動作選單

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 按鈕點開是一串動作，按鈕上的字不會變
  • 「更多」按鈕點開的指令清單

也叫：menu buttondropdown menuactions menu更多選單動作選單

AI prompt

Build a iOS Pull-down button (UIButton (menu + showsMenuAsPrimaryAction) or Menu). Also known as: menu button, SwiftUI Menu. It should have: button label stays fixed; opens a list of commands; chevron down. Do not build a Pop-up select.
