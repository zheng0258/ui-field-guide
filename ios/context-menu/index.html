Context menu 情境選單

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 按右鍵或長按才會跳出來的選單
  • 針對你點的那個東西列出能做的事

也叫：right-click menushortcut menulong-press menu右鍵選單長按選單

AI prompt

Build a iOS Context menu (UIContextMenuInteraction or .contextMenu). Also known as: right-click menu, SwiftUI contextMenu. It should have: appears at pointer; actions for the clicked item. Do not build a Pull-down menu.
