# UI Field Guide

Cross-platform UI component field guide: one concept, four platform names
(macOS, iOS, Android, Web). Tagline: "Spot it, name it, prompt it."
Communicate with the user in Traditional Chinese.

## Source of truth

- Content lives in `content/<kind>/<id>.yaml`, validated by Zod in `src/schema/`.
- Never hard-code component names or API mappings in Vue files; read them from content.
- Research and decisions: `docs/handoff.md` (read first), platform tables in `docs/platforms/`,
  architecture decisions in `docs/decisions/`, research snapshot in `docs/research.md`.

## Stack

Vue 3, TypeScript, Vite, vite-ssg (see `docs/decisions/0001-prerender-vite-ssg.md`), pnpm,
XState v5, plain CSS custom properties (no Tailwind), Fuse.js, Vitest, Playwright, axe.

## Layout

- `src/content/validate.ts` parses + validates + cross-checks content; `vite.config.ts` loads it as
  `virtual:content` and fails the build on any issue. Drafts ship only when
  `INCLUDE_DRAFTS=1` (dev, PR previews, and — temporarily — the production deploy in
  `.github/workflows/deploy.yml`; each draft page says it is unverified).
- Routes are platform-first: `/` → `/<platform>` (grid with thumbnails) → `/<platform>/<id>`
  (see `docs/decisions/0002-platform-first-flow.md`).
- Demos are plain HTML in `src/demos/<platform>/<id>.html` (optional `<id>.thumb.html` for the
  thumbnail), rendered live and shown as source; shared behaviors live in `src/demos/behaviors.ts`
  and attach by data attributes / ARIA roles. Every concept with a Web entry must have a Web demo.
- Browser code imports runtime values from `src/schema/constants.ts` (no Zod in the bundle);
  `src/schema/index.ts` is for validation and types.
- `tools/measure-macos` (Swift) → `tools/measure-macos/output/macos.json` → `scripts/build-tokens.ts`
  → `src/tokens/macos.css`.

## Hard rules

- Do NOT bundle SF Pro or any Apple font file. Use `system-ui, -apple-system, sans-serif`.
- Do NOT use SF Symbols artwork. Use Lucide, Phosphor or hand-drawn SVG.
- No Apple logos or official device images.
- Design tokens in `src/tokens/` are generated by `tools/measure-macos`; never edit by hand.
- Demos must be keyboard operable and respect prefers-reduced-motion,
  prefers-reduced-transparency and forced-colors.
- Liquid Glass refraction is Chromium-only; Safari parses `backdrop-filter: url()`
  but renders nothing, so do not rely on `@supports` alone.
- Do not use CSS variables inside `-webkit-backdrop-filter`.
- iOS and Android are separate platforms; never merge them as "mobile".

## Commands

- `pnpm dev` / `pnpm build` / `pnpm test` / `pnpm test:visual` / `pnpm lint` / `pnpm typecheck`
- `pnpm content:check` validates all YAML and cross-references.
- `pnpm tokens:measure` (macOS only) then `pnpm tokens:build` regenerates design tokens.

## Done means

CI green (lint, typecheck, schema, visual, axe), new concepts have `status: draft`
until API mappings are verified against official docs.
