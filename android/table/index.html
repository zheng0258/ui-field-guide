List 表格

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 一列一列的資料，有欄位標題

也叫：data table表格視圖

範例

  • AAmy Chen明天的會議改到 3 點10:42
  • BBen Lin照片已上傳昨天

AI prompt

Build a Android List (LazyColumn + ListItem or RecyclerView). Also known as: HTML table with caption and th scope. It should have: header row; zebra striped rows. Do not build a Data grid.
