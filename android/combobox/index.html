Exposed dropdown menu (editable) 組合框

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 可以打字也可以從清單挑的輸入框
  • 邊打字邊跳出建議選項

也叫：autocompletetypeaheadeditable dropdown自動完成可輸入下拉

AI prompt

Build a Android Exposed dropdown menu (editable) (ExposedDropdownMenuBox + TextField or MaterialAutoCompleteTextView). Also known as: NSComboBox, autocomplete text field. It should have: editable text field; dropdown arrow; suggestion list. Do not build a Pop-up select.
