Progress indicator 進度條

草稿：名稱與 API 對應尚未對照官方文件驗證，使用前請先確認。

  • 一條慢慢填滿的橫條，表示完成多少

也叫：progressloading bar進度

範例

正在上傳 3 張相片
HTML 原始碼
<div class="stack">
  <span>正在上傳 3 張相片</span>
  <div class="linear" role="progressbar" aria-valuenow="60" aria-valuemin="0" aria-valuemax="100" aria-label="上傳進度">
    <span class="active" style="width: 60%"></span><span class="track"></span><span class="stop"></span>
  </div>
</div>

AI prompt

Build a Android Progress indicator (LinearProgressIndicator or LinearProgressIndicator). Also known as: HTML progress element. It should have: horizontal bar filling left to right; percentage label. Do not build a Meter.
