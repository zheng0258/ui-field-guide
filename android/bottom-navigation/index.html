AI prompt

Build a Android Navigation bar (NavigationBar + NavigationBarItem or BottomNavigationView). Also known as: iOS tab bar, Material navigation bar. It should have: 3 to 5 icon destinations with labels; selected destination highlighted. Do not build a Tabs.
